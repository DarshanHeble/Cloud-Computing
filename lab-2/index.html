Why this works for Lab 2

Static sites are the simplest way to show cloud hosting basics.

A static website is ideal for S3 because the browser downloads files directly from storage. That makes it easy to explain upload, endpoint configuration, permissions, and error handling.

  • Index page for the main site entry point
  • Custom 404 page for invalid paths
  • Three image assets for a realistic website structure
  • JavaScript to show a live timestamp and simple interaction
